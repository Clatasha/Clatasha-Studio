# Clatasha Studio Roadmap

This roadmap tracks broad development goals. It does not promise release dates, and priorities may change as Clatasha Studio is tested.

## Completed foundations

- Layer-based canvas editor
- Image, text, shape, and drawing tools
- Groups, clipping, alignment, guides, rulers, and snapping controls
- Transform handles that remain accessible outside the document canvas
- Image adjustments and visual adjustment presets
- Plugin installation and management framework
- PNG, JPG, and WebP export
- Default and Bowetech themes
- Offline Image Merger, Image Cipher, and Image to SVG plugins
- Locally saved editable templates with generated previews
- Dedicated YouTube and Shorts template sections

## Current focus

- Improve stability across larger projects and long editing sessions
- Refine drag-and-drop, transforms, cropping, and grouped-object editing
- Improve tracing accuracy and SVG output efficiency
- Review keyboard access, tooltips, error messages, and first-use guidance
- Expand internal compatibility and release testing
- Refine public source documentation and automated package validation

## Before public availability

- Complete a full Chrome compatibility pass
- Complete privacy, permission, and package reviews
- Finalize store listing material and installation guidance
- Prepare a public support process
- Publish an official availability announcement

## Future ideas

These ideas are being considered and are not confirmed release commitments.

- More Clatasha plugins
- Additional themes and workspace customization
- Expanded non-destructive image controls
- More templates, graphics, and design presets
- Broader plugin documentation for third-party developers

## Public release status

Clatasha Studio's current source is publicly available from this repository. The project remains in active development, and GitHub Actions produces a testable Chrome package artifact from `main`.

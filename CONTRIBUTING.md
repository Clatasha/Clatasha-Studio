# Contributing and Feedback

Thank you for following Clatasha Studio.

Clatasha Studio is currently proprietary software in private development. The application source is not hosted in this repository, and source-code pull requests cannot be accepted at this stage.

## Feature ideas

Use the **Feature request** issue form. Explain the problem you want to solve and how the proposed behavior would fit into a normal editing workflow.

## Bug reports

Bug reports are currently intended for approved testers. Include:

- The Clatasha Studio version
- Clear reproduction steps
- What you expected to happen
- What happened instead
- Browser and operating-system details
- A screenshot when it does not contain private material

Do not upload private projects, passwords, encryption keys, unreleased packages, or personal images to a public issue.

## Pull requests

Documentation corrections may be reviewed in the future. Application-code contributions are not being accepted while the source remains private.

## Conduct

Keep discussions respectful, specific, and focused on improving Clatasha Studio.

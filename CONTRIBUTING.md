# Contributing and Feedback

Thank you for helping improve Clatasha Studio.

## Feature ideas

Use the **Feature request** issue form. Explain the editing problem and how the proposed behavior would fit into a normal workflow.

## Bug reports

Include:

- The Clatasha Studio version
- Clear reproduction steps
- What you expected to happen
- What happened instead
- Chrome and operating-system versions
- A screenshot when it does not contain private material

Do not upload private projects, passwords, encryption keys, unreleased packages, or personal images to a public issue.

## Pull requests

Small, focused pull requests may be reviewed. Open an issue before beginning a large feature or structural rewrite. A submitted pull request does not guarantee that the change will be accepted.

Keep unrelated formatting or generated-file changes out of the pull request. Test the unpacked extension in Chrome and describe what you tested.

## Conduct

Keep discussions respectful, specific, and focused on improving Clatasha Studio.
